Este soy yo

No soy solamente un CV. Soy una persona construyendo su camino en la tecnología.

Tengo 19 años y soy Tecnólogo en Análisis y Desarrollo de Software del SENA. La tecnología no es solamente algo que estudio — es una herramienta que me permite crear, resolver problemas, automatizar procesos y convertir ideas en productos digitales.

Qué he construido

Cada proyecto cuenta una historia: por qué nació, qué aprendí, y qué haría diferente.

Proyecto destacado

Artesanías & CO

Plataforma digital orientada a artesanos para convertir una idea de negocio en una solución digital.

🎯 El problema

Los artesanos necesitan herramientas digitales accesibles para gestionar y mostrar sus productos, pero las plataformas existentes no están diseñadas para sus necesidades específicas.

💡 La idea

Crear una plataforma que ayude a artesanos a digitalizar su negocio — desde la gestión de productos hasta la comunicación con clientes.

💻 Mi participación

Participé activamente en el desarrollo técnico del proyecto, trabajando tanto en el frontend como en el backend, la base de datos y la infraestructura.

Tecnologías que utilicé
Frontend
Next.js React Tailwind CSS DaisyUI Axios React Context React Hook Form
Backend
Node.js Express JWT Multer Nodemailer ioredis ExcelJS PDFKit
DB & Infra
PostgreSQL Docker Docker Compose Nginx GitHub Actions

💻 Funcionalidades principales

  • ▸ Gestión de productos y catálogo
  • ▸ Sistema de autenticación con JWT
  • ▸ Reportes en Excel y PDF
  • ▸ Envío de correos electrónicos
  • ▸ Panel de administración
  • ▸ Gestión de archivos e imágenes
  • ▸ Formularios de contacto

📖 Lo que aprendí

  • ✦ Cómo estructurar un proyecto full-stack con separación clara entre frontend y backend
  • ✦ Implementación de autenticación segura con JWT y manejo de sesiones
  • ✦ Generación de documentos dinámicos (PDF y Excel) desde el servidor
  • ✦ Configuración de contenedores Docker para desarrollo y despliegue
  • ✦ Integración de servicios de correo electrónico
  • ✦ Manejo de archivos y almacenamiento de imágenes

🔄 Qué haría diferente

  • → Implementaría testing desde el inicio del proyecto
  • → Mejoraría la documentación técnica y de API
  • → Utilizaría TypeScript en el backend para mayor seguridad de tipos
Proyecto destacado

Wonder Flowers

Experiencia digital para una floristería — combinando e-commerce, diseño, automatización y chatbot con IA.

🎯 El problema

Una floristería necesita una presencia digital que no solo muestre sus productos, sino que guíe al cliente desde el descubrimiento hasta la compra, de manera cálida y personalizada.

💡 La idea

Crear una experiencia digital completa que incluya catálogo, diseño visual atractivo, y un chatbot inteligente que ayude a los clientes a encontrar el arreglo perfecto.

💻 Mi participación

Trabajé en el desarrollo web, diseño visual, integración con Shopify, y desarrollé conceptualmente el chatbot Wonder Flowers Assistant para automatizar la atención al cliente.

  • ▸ Diseño visual y UX

  • ▸ Integración con WhatsApp
